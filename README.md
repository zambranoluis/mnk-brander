# mnk-brander

A studio for brand and product development: strategy, identity, websites, interfaces, landing pages, prototypes and related design. New videos of any type go through Filmmaker (`mnk-filmmaker`, alias `filmmaker`). Existing Brander films keep their recorded owner and editing associations. Executable applications and product facts stay in dedicated product repositories; physical construction is outside scope.

## Start here

Read [AGENTS](AGENTS.md) and [studio requirements](STUDIO.md). Independent work uses the local methods and requirements in this repository. Base-led work uses the selected base's methods and these same requirements. The task/session supplies the selected central workspace location; no external policy installation is required.

## Locations and boundaries

The [architecture owner](ARCHITECTURE.md) maps sources and products. New recorded tasks live at `<workspace>/<task-name>/task.md` in the selected central project workspace. [PRODUCTION](PRODUCTION.md#revisions-and-records) defines editable work, disposable files, meaningful versions and requested exports. Existing production layouts and histories stay where found.

## Tools and prerequisites

Run `python -B scripts/check_docs.py` and `python -B -m unittest discover -s tests -p test_check_docs.py -v` from this repository for documentation/tooling changes. The [engineering owner](ENGINEERING.md) explains optional method checks, conditional production checks and missing film build prerequisites. Documentation checks do not establish production readiness.

## Documentation map

[AGENTS](AGENTS.md#routing) routes local methods. The [studio entry](STUDIO.md) routes brand/product work, new filmmaking and retained commercial requirements. Read only the affected owners. Retained media establish file presence, not an editing baseline, reproducible source package or approval.
