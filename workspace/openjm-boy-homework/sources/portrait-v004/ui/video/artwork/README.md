# Water cycle illustrations and board

The four PNG illustrations contain no lettering and can be reused independently. Evaporation and Precipitation are byte-identical retained sources. Condensation and Collection were generated with the built-in image tool against both retained references; the exact prompts and the Condensation correction are in [prompts.json](prompts.json).

`board.svg` is the editable 1920×1080 composition. Each labelled group contains an illustration and a separate editable `<text>` label and directional `<path>`. The embedded images make the SVG independently portable. Edit the text and paths in an SVG editor, or change `board.json` and run the packaged board builder. `board.png` is the rendered version shown as **one** native image result with identity `immersive-water-cycle-board`.

Reading order is left to right, top to bottom: Evaporation, Condensation, Precipitation, Collection. Arrows are schematic teaching aids. The fine droplets at the Condensation cloud edge are liquid water; invisible vapour is not drawn as smoke. The retained Evaporation landscape also contains distant rain, as in the original source: it depicts the shared cycle environment while its upward arrow identifies the focused process.

The board label size is 76 source pixels, yielding more than 31 displayed pixels during the review's board hold. The two generated views retain the river entering from the right, the lake, mountains, miniature materials and warm daylight. A first Condensation candidate with oversized glass drops was rejected before this board was assembled.

Only the later presentation specification is prepared. See [PRESENTATION.md](../PRESENTATION.md) for the 400-frame playback and 50-frame replay hold requirement.
