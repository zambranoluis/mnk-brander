# Portrait images editable source

Independent retained and adapted project. Render at 360 x 640 CSS pixels with deviceScaleFactor 3. See [the portrait package instructions](../../README.md) for reproduction and verification.

The release timestamps, conversation wording and selected assets are retained. Mobile staging uses ../portrait.js, ../portrait.css and ../touch.js for the four chat scenes. The presentation uses its own proportional-fitting CSS and 400-frame clock. Outputs are silent scene media; the AAC soundtrack is copied during assembly.

Use the package-level capture script, not inherited desktop rendering commands. After editing a scene script or content file, run this directory's sync-source.cjs from Node if present. Do not rerun the inherited desktop board/source capture tools for this portrait build.
