# Investigations

Use under [AGENTS](../../AGENTS.md) to ground a decision, answer or implementation. Read the [studio entry](../../STUDIO.md), select the explicit task/production and inspect only affected owners. Keep source, home and delivery location distinct. Existing names resume their record; a new task uses a clear unused name. Ambiguous target identity blocks dependent writes.

## Sufficiency test

Identify the governing requirement, decision owner, relevant producers/consumers and checks. Inspect facts and constraints without recursively entering every linked workflow. Resolve material unknowns before dependent work. A factual answer may end here.

## Evidence and boundaries

Separate supplied direction, documented capability, observed implementation and inference. Use current official sources for changing host, model or provider facts. A tool's presence is not successful execution, account access or production readiness. Related product knowledge does not authorize edits to that product.

## Investigation record

Keep costly findings, sources, limits and unresolved effects in the selected task.md. Split out substantial research only when useful. Do not make history, personal memory or a temporary record the sole source of standing policy.

## Evidence-dependent stops

Missing access blocks work that requires the unavailable observation. Continue independent authorized work when requirements and sources suffice. Report the missing owner/input and exact remaining check; never substitute a mock for live evidence or invent an available film source package.
