# Verification standard

Use under [AGENTS](../../AGENTS.md). The [engineering owner](../../ENGINEERING.md) declares commands and prerequisites; [PRODUCTION](../../PRODUCTION.md) owns delivery states.

## Common verification

Choose evidence from the changed responsibility, acceptance and configured gates. Inspect actual results and scoped diffs, including untracked files and whitespace. Repeat or broaden checks only for changes, failures, required gates or unresolved risk. Never fabricate a check or turn an unavailable prerequisite into a pass.

| Property | Evidence and limit |
| --- | --- |
| Documents and instructions | Read the complete affected chain; check ownership, facts, links, anchors and exceptions. Static checks do not prove agent behavior or host loading. |
| Tools and software | Focused regression/failure tests plus configured gates. Controlled fixtures do not establish live provider behavior. |
| Visual artifacts and interfaces | Inspect rendered outputs, required formats and relevant interaction/layout states. Static source does not prove visual quality; browser simulations do not prove native/device behavior. |
| Film and sound | Inspect states, timing, full playback and sound as required. Metadata and samples cannot establish pacing or human listening approval. |
| Copies and handoffs | Check selected files, bytes when identity matters, dependencies and destination use. Hashes and links do not establish semantic completeness or creative quality. |

## Documents and instructions

Run the declared documentation checker and focused checker tests when changing that mechanism. Trace representative tasks and review the canonical chain without temporary records or external policy content. Report controlled-fixture independence separately from actual host execution.

## Creative work

Judge actual output against brief, selected direction and medium requirements; correct material defects within scope. Report technical checks, craft assessment, delivery and user approval separately. An explicit required human review remains pending until supplied.

## Commercial checks

[COMMERCIAL](../../COMMERCIAL.md#commercial-verification) owns selected assets, continuity, prompts, sound, handoff and conditional package checks. Apply them only to the selected production responsibility. A documentation revision does not require synthetic production packages.
