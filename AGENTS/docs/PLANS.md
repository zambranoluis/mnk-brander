# Plans

Use for a requested plan or consequential dependencies under [AGENTS](../../AGENTS.md). One clear correction can remain conversational.

## Preparing and presenting

Ground the target and affected owners using [INVESTIGATIONS](INVESTIGATIONS.md). State intended behavior, authorized writes and stop. Recommend feasible choices using the brief; routine technique is the agent's responsibility. Ask only for an unresolved choice that materially changes the result or commitment.

## Plan structure

Explain required changes, dependency order, acceptance, checks and material unknowns. Separate proposals from settled decisions. Scale detail to the work; file count alone does not require more ceremony. Keep one authoritative task record and link a separate plan only when its content warrants it.

## Corrections and saving

Revisit the affected decision when evidence changes. Saving a plan authorizes that record only; it does not authorize implementation. Preserve explicit user review stops and existing outputs.
